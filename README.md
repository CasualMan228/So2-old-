# So2 (old)

Автоматизированный скрипт для внутриигрового трейдинга скинами на рынке Standoff 2, разработанный в 2024 году (давно)

## Особенности и технологии
Computer Vision (OpenCV) -> анализ экрана, поиск и сопоставление шаблонов предметов для точного определения скинов;
Optical Character Recognition (Tesseract OCR) -> автоматическое распознавание и парсинг текстовых данных (цен на рынке) прямо со скриншотов эмулятора;
GUI Automation (PyAutoGUI) -> эмуляция действий пользователя (клики, скроллинг, ввод текста) для управления игровым процессом в BlueStacks;
Data Logging -> запись успешных ордеров и логов в файл (OrderedCells.txt) для отслеживания истории закупленных предметов.
